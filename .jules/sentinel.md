## 2026-11-03 - Missing Directory and Logger Fallback in Internal Routes
**Vulnerability:** In `api_server/routes/internal/internal_routes.py`, `get_files` invoked `os.scandir(directory)` without checking if `directory` existed or was `None`, resulting in unhandled `FileNotFoundError` (HTTP 500) when optional directories such as `temp` were not created yet on disk. Similarly, `get_logs` and `get_raw_logs` assumed `app.logger.get_logs()` always returned an iterable, throwing `TypeError` (HTTP 500) if accessed prior to logger initialization.
**Learning:** Internal server endpoints that interact with local storage or state should defensively verify existence of directories and initialize fallbacks rather than relying on directory creation by background processes or execution side-effects.
**Prevention:** Always check `if not directory or not os.path.exists(directory)` before scanning filepaths and default to safe empty fallbacks (`[]`) for uninitialized system state in API routes.
