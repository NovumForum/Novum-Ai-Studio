## 2026-08-05 - Model Preview Path Traversal & Internal Route Scandir Fallback
**Vulnerability:** Path traversal on the experimental model preview route allowed arbitrary image reading and safetensors metadata loading from the filesystem. Additionally, an index/value error on the same route caused unhandled exception crashes. Furthermore, the internal files route performed `os.scandir(None)` when directories were unconfigured/None, causing it to fall back to the root workspace directory and leaking the repository structure.
**Learning:** Experimental endpoints and internal utility functions are often written with assumptions that parameters are pre-validated (e.g. `path_index` is always in range, `directory` is always configured, `filename` is sanitized). These assumptions break down under direct API access.
**Prevention:** Always check boundaries on collection lookups (using `0 <= index < len`), sanitize/bound nested relative path segments via `os.path.commonpath` comparisons with resolved absolute paths, and ensure target directories exist and are valid via `os.path.isdir` before scanning files.
