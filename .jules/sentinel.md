## 2026-09-29 - Path Traversal & Unhandled Parameter Errors in Model Preview Endpoint
**Vulnerability:** The model preview route `/experiment/models/preview/{folder}/{path_index}/{filename:.*}` accepted raw `filename` parameters without validating that `full_filename` stayed within the intended base directory, enabling path traversal out of model directories. Additionally, invalid `path_index` parameter types or out-of-bound indices raised unhandled `ValueError` and `IndexError` exceptions (HTTP 500).
**Learning:** Route parameters matching greedy wildcard paths (`{filename:.*}`) bypass simple URL path checks and can reference paths outside the root folder when combined with `os.path.join`. Furthermore, array lookups and type casts on match_info parameters without try-except blocks or bounds checks cause internal server error (500) disclosures.
**Prevention:** Always validate path safety using `os.path.commonpath((os.path.abspath(target), os.path.abspath(base))) == os.path.abspath(base)` before accessing files, and validate integer route parameters with try-except blocks and bounds checking before indexing arrays.
