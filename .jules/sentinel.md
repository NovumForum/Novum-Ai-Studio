## 2026-03-01 - Directory Contents Leakage via os.scandir(None)
**Vulnerability:** In python, calling `os.scandir(None)` defaults to the current working directory (`'.'`). Consequently, an endpoint expecting a directory path string that passes a `None` value to `os.scandir` without validating it will accidentally list and expose the entire application's root directory contents, including source code and configuration files.
**Learning:** Functions that return directory paths (e.g., `folder_paths.get_directory_by_type`) can return `None` if they are not configured or initialized. Treating the return value as a guaranteed string and passing it directly to `os.scandir` introduces a critical directory leakage vulnerability.
**Prevention:** Always validate that the directory path is a non-empty string and a valid directory (using `os.path.isdir`) before calling directory-scanning functions like `os.scandir` or `os.listdir`. Wrap filesystem operations in a try-except block to handle general `OSError` and return generic, non-disclosing error messages.
