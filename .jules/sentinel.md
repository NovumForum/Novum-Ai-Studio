## 2026-10-03 - Model Preview Route Path Traversal and Parameter Validation
**Vulnerability:** The `/experiment/models/preview/{folder}/{path_index}/{filename:.*}` route in `app/model_manager.py` did not validate path traversal on `filename`, performed direct integer casting `int(path_index)` without try-except handling, and lacked array bounds checking on `folders[0][path_index]`. This allowed relative path traversal and could trigger unhandled 500 server errors on invalid inputs.
**Learning:** Route parameters matching wildcard patterns like `{filename:.*}` can receive relative path components. In addition, route parameters passed directly to array indexing must be validated against array bounds and safely parsed for integer conversion.
**Prevention:** Always validate `{filename:.*}` against target directory boundaries using `os.path.commonpath`, safely parse integer query/path parameters with try-except blocks returning HTTP 400 Bad Request, and check array bounds returning HTTP 404 Not Found before indexing.
