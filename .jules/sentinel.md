## 2026-08-09 - Path Traversal in Model Preview Endpoint
**Vulnerability:** The experimental `/experiment/models/preview/{folder}/{path_index}/{filename:.*}` endpoint was vulnerable to path traversal (arbitrary file read / leakage) and unhandled `IndexError` crashes because it resolved paths using simple string concatenation without validating that the resolved absolute path remained within the intended directory boundaries, and did not check `path_index` bounds.
**Learning:** Standard client/browser URL normalization can be bypassed using URL encoding (e.g. `%2E%2E%2F` or double URL encoding). When endpoints parse wildcard filename paths or decode path parameters manually or automatically, relying on naive string joins or simple checks is insufficient to prevent traversal.
**Prevention:** Always resolve the absolute canonical path of both the target file and the parent directory using `os.path.realpath` (to resolve symlinks and relative path segments), and check that they share the exact parent path containment using `os.path.commonpath`. Additionally, validate all path or collection index parameters (like `path_index`) against non-negative bounds before using them.
