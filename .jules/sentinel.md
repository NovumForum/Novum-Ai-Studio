## 2025-05-20 - Model Preview Endpoint Path Traversal and Index Bounds Risk
**Vulnerability:** The `/experiment/models/preview/{folder}/{path_index}/{filename:.*}` endpoint in `app/model_manager.py` directly concatenated `folder` and user-controlled `{filename:.*}` wildcard route parameters with `os.path.join`, enabling path traversal to read files outside the designated model directory. Furthermore, raw `int()` casting on `path_index` and unchecked indexing into `folders[0]` caused unhandled `ValueError` and `IndexError` 500 server errors.
**Learning:** Wildcard subpath routes like `{filename:.*}` bypass standard single-segment path sanitization and require explicit canonical path normalization and `os.path.commonpath` validation against the root directory before performing file operations or passing to `glob`/`PIL`.
**Prevention:** Always normalize target file paths using `os.path.abspath` and verify `os.path.commonpath([base_dir_abs, target_file_abs]) == base_dir_abs` for all file-serving endpoints. Wrap user-supplied index parsing in `try...except` and validate list bounds to fail gracefully with HTTP 400/404.
