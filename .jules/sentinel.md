## 2026-09-20 - Model Preview Endpoint Path Traversal and Unhandled Input Errors
**Vulnerability:** Unsanitized `filename` in `/experiment/models/preview/{folder}/{path_index}/{filename:.*}` allowed arbitrary path traversal when constructing `full_filename`. Furthermore, `path_index` was directly converted to `int` and used as an array index without bounds checking or exception handling, causing HTTP 500 internal server errors on invalid inputs.
**Learning:** `os.path.join` does not prevent path traversal if `filename` contains `..` components. Moreover, match parameters in aiohttp routes must be explicitly parsed and bounds-checked to avoid uncaught exceptions during request handling.
**Prevention:** Always sanitize/resolve file paths using `os.path.abspath` and verify containment with `os.path.commonpath([abs_folder, full_filename]) == abs_folder`. Ensure integer route parameters are safely converted inside a `try-except` block and checked against valid collection bounds before indexing.
