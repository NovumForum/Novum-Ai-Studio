## 2026-09-14 - Path Traversal & Unhandled Parameter Conversion in Model Preview Endpoint
**Vulnerability:** The `/experiment/models/preview/{folder}/{path_index}/{filename:.*}` endpoint accepted arbitrary path strings via `{filename:.*}` without validating that the target path remained inside the model directory, allowing path traversal outside the designated folder. Additionally, `path_index` was converted to `int` without input validation or bounds checking, causing unhandled `ValueError` and `IndexError` exceptions.
**Learning:** Wildcard path match parameters in web framework route signatures (like `{filename:.*}`) allow directory traversal sequences (`..`) unless explicitly checked with `os.path.commonpath`. Converting route parameters directly without error handling also creates DoS / 500 error risks.
**Prevention:** Always validate integer bounds and type conversions on route parameters, and use `os.path.commonpath([abs_base_dir, abs_target_path]) == abs_base_dir` to ensure requested file paths remain constrained within allowed base directories.
