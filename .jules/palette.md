## 2025-02-15 - Visual Controls for Complex Parameters
**Learning:** Integer-based parameters representing hex colors (such as the `color` input of `ImageColorToMask`) present a significant cognitive load and accessibility barrier if rendered as plain text/numeric inputs, forcing users to manually calculate or copy-paste decimal color representations. Similarly, bounded decimal inputs (0.0 to 1.0) require manual validation and keystrokes. Using display modes like `color` and `slider` offloads these operations to interactive, accessible visual controls on the frontend.
**Action:** When defining schemas for inputs representing colors or bounded numeric ranges, prioritize specialized display modes (like `IO.NumberDisplay.color` and `IO.NumberDisplay.slider`) to reduce cognitive load and prevent input validation errors.
