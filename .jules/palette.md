## 2025-02-18 - Input Parameter Tooltips and Node Search Aliases
**Learning:** Adding descriptive tooltips and search aliases to modern nodes in ComfyUI backend schemas dramatically improves discoverability and onboarding for end users, allowing them to use synonyms and hover over inputs to understand advanced mathematical parameters.
**Action:** Always declare comprehensive tooltips, descriptive search aliases, and node-level descriptions for all inputs when defining or modifying V3 node schemas.
