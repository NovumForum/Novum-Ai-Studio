## 2025-02-13 - Node Schema Tooltips for Screen Readers & Contextual Help
**Learning:** In node-based visual programming interfaces like ComfyUI, users frequently struggle to understand non-obvious properties like stitching dimensions, resizing ratios, and padding rules. Screen readers and in-context search assistants rely heavily on dynamic schema-level tooltips, aliases, and node-level descriptions to render descriptive UI helps.
**Action:** Always enrich node schemas with precise parameter-level tooltips and standard search aliases to improve discoverability and accessible context helper visibility.
