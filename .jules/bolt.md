## 2026-03-01 - Replacing Manual Linear Interpolation with Fused torch.lerp in ConditioningAverage
**Learning:** Manual linear interpolation patterns using arithmetic operations (e.g., `t1 * w + t0 * (1 - w)`) are highly inefficient in PyTorch. They trigger multiple individual element-wise kernel launches and allocate several intermediate temporary tensors. Refactoring these to use PyTorch's native, fused `torch.lerp(start, end, weight)` operator (e.g., `torch.lerp(t0, t1, w)`) delegates the interpolation to a single optimized, fused kernel, significantly improving performance, lowering memory bandwidth pressure, and avoiding redundant allocations.
**Action:** Actively scan high-frequency conditioning and model blending code paths for manual linear interpolations, and refactor them using PyTorch's native fused `torch.lerp` to achieve maximum efficiency.
