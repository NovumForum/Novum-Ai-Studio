## 2025-10-16 - Vectorized Porter-Duff Image Composite Batch Operations
**Learning:** In `PorterDuffImageComposite.execute` (`comfy_extras/nodes_compositing.py`), processing image batches with a per-frame Python `for` loop and `torch.stack` incurs significant Python interpreter overhead and forces sequential upscale and compositing function calls. Since PyTorch 2D upscaling and elementwise operations natively support 4D batch tensors `[B, H, W, C]`, replacing the loop with 4D tensor operations enables parallel execution and zero-copy tensor slicing.
**Action:** When working on compositing or image manipulation nodes that process batch lists, vectorize shape checks, channel assertions, upscaling, and mathematical functions directly on 4D batch tensors `[B, H, W, C]` or `[B, C, H, W]`.
