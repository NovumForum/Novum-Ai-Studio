## 2025-02-22 - Vectorized Morphological Operations in PyTorch
**Learning:** In ComfyUI mask processing nodes, converting PyTorch tensors to NumPy arrays to perform morphological operations (like grey dilation/erosion via SciPy) introduces heavy CPU-GPU transfer overhead and Python loop bottlenecking. Vectorizing morphological operations directly in PyTorch using `F.pad(..., mode="reflect")`, `F.max_pool2d` (for 3x3 square kernels) and elementwise neighborhood maximums (for cross kernels) yields up to 12.5x speedups while running natively on GPU/MPS and maintaining 100% numerical equivalence with SciPy.
**Action:** When optimizing mask nodes using SciPy `ndimage` functions, replace array conversion and per-item Python loops with native PyTorch tensor operations (`F.pad`, `F.max_pool2d`, `torch.maximum`).
