## 2025-02-14 - Fused torch.lerp for High-Performance Tensor Interpolation
**Learning:** Manual linear interpolation using standard arithmetic operators `a * w + b * (1.0 - w)` or `torch.mul` calls are highly suboptimal in PyTorch because they require multiple intermediate tensor allocations and memory passes. Utilizing `torch.lerp(b, a, w)` delegates the interpolation to a single fused GPU/CPU kernel, resulting in a ~2.75x to 3.02x execution speedup (approx. 67% reduction in execution time) for typical latent and conditioning tensor shapes while maintaining mathematical equivalence (up to floating-point representation limits).
**Action:** Always identify manual interpolation patterns in high-frequency node logic and refactor them to use PyTorch's native `torch.lerp` for fused execution.
