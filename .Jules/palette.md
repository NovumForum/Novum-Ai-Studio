## 2025-02-23 - Search Aliases & Parameter Tooltips for Specialized UI Nodes
**Learning:** Adding search aliases (`search_aliases`) and clear input tooltips (`tooltip`) to custom UI nodes like `ImageCompare` significantly improves node discoverability in search menus and gives users clear contextual guidance directly within the visual workspace.
**Action:** Always include comprehensive `search_aliases` and input/output parameter `tooltip` properties when defining `IO.Schema` or legacy node class schemas.
