## 2025-02-17 - Declarative In-Context UX and Discoverability in V3 Node Schemas
**Learning:** In ComfyUI's modern V3 architecture, input parameters of custom widget types (such as `IO.ImageCompare.Input`) subclass `WidgetInput` which fully supports declarative `tooltip` arguments in Python. Additionally, the node-level `Schema` directly consumes `search_aliases` and `description` fields. This enables complete, accessible, and highly searchable in-context guidance to be injected directly from the backend node definition without requiring any frontend code changes.
**Action:** Always enrich custom V3 nodes with node-level `search_aliases`, a comprehensive `description`, and parameter-level `tooltip`s to dramatically reduce interface ambiguity and facilitate keyboard/search-first interaction.
