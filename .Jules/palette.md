## 2025-05-20 - PreviewAny Node UX Tooltips and Description
**Learning:** Adding explicit node descriptions (`DESCRIPTION`) and parameter tooltips (`tooltip`) to utility nodes such as `PreviewAny` ("Preview as Text") significantly improves discoverability and context during workflow construction in ComfyUI canvas search and node properties panel.
**Action:** Always verify that utility/inspection nodes expose a concise `DESCRIPTION` and `tooltip` metadata on input parameters.
