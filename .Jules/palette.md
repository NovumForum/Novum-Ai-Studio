## 2025-05-15 - Visual Color Picker for Better Node Intuition
**Learning:** Providing a visual hex color picker (`IO.Color.Input`) is significantly more intuitive than separate R, G, B integer inputs, especially for artistic tools like Recraft. It allows users to see the color they are selecting directly in the node interface, reducing the cognitive load of translating RGB values to visual colors.
**Action:** Prefer `IO.Color.Input` for single-color selection nodes in the V3 API to enhance visual feedback and ease of use.
