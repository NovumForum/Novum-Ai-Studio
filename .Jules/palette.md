## 2025-02-14 - Improve Color Keying UX with Visual Color Picker
**Learning:** In `comfy_extras/nodes_mask.py`, the `ImageColorToMask` node accepts an integer `color` parameter. Previously, it had `display_mode=IO.NumberDisplay.number`, forcing the user to manually enter raw hex/integer values (e.g. `16711680` for red) instead of interacting with a visual element. By adding a dedicated `"color"` display mode to the API's `NumberDisplay` registry and applying it (`display_mode=IO.NumberDisplay.color`), the UI can automatically mount a visual color picker, dramatically improving user interaction and speed of color keying operations.
**Action:** Always check if a node's parameter represents colors, gradients, or numerical ranges and map them to their corresponding visual displays (e.g., `NumberDisplay.color`, `NumberDisplay.slider`) instead of standard input boxes to maximize intuitive interaction.
